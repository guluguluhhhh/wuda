# DSV4 Megakernel 性能报告（B300）

解码链：`mhc → front_mixed_gemm → qnorm_quant(PDL) + wq_b → mqa_logits(score attn) → topk → FlashMLA`

## 总结

- **mhc**：五级小算子链（分离串行 ≈10.5us+launch）收进单 kernel，总时长 11.5~15.5us，仅比裸 cuBLAS GEMM 贵 0.7~3us；attn_norm / fp8 量化 epilogue 融合近乎免费。
- **front_mixed**：混合精度比全 bf16 cuBLAS 快 1.09~1.16x，hc tail 免费；~2.9TB/s。
- **wq_b**：六项 CUDA-core 融合总代价 d_all 0.2~2.9us（GEMM 的 1~10%），fused 达 cuBLAS 的 93~108%——post/ssq/comp/win/quant 全部近乎无损藏进 27us GEMM 窗口，4.2~4.7TB/s。
- **score attention**：compressor tail（独立跑 4.5us）融合后 d ≈ 0，完全免费；对比分离方案加速 1.01~1.83x（短 ctx 收益最大，launch+串行占比高）；1M ctx 下 6.6TB/s 逼近带宽 roofline。
- **e2e（64k）**：graph 98.6~194.4us/step；有效带宽 EFF 1.7~2.3TB/s。B=128 下 mla(78.7us) + mqa(34.5us) 合计占 stages 的 60%，是仅剩的两个低带宽利用大户（1.5 / 4.6TB/s，mla 含 28% 内部流量）；topk 有效字节为 0（纯中间量），是 megakernel 化的下一个吸收目标。
- **全链**：四个大算子已把 DSV4 decode 层的全部小算子（norm/quant/rope/hadamard/compressor/window/ssq）吸收，kernel 数 = 4 + topk + FlashMLA，中间量零独立 kernel。
